# TechTrack: Real-Time Object Detection System

**Johns Hopkins University | EN.705.603 Creating AI-Enabled Systems | Fall 2026**

TechTrack is a computer vision case study examining the evaluation and deployment considerations of a real-time object detection system built around YOLOv4-Tiny.

The project evaluates two trained model variants and explores several system design decisions, including:

- Model selection using overall and class-level detection performance
- Representative dataset sampling
- Non-maximum suppression (NMS) threshold optimization
- Robustness to image transformations
- Hard-negative mining and loss-based error prioritization

The analysis also considers how model evaluation connects to broader engineering concerns, including containerization, video inference, deployment tradeoffs, and monitoring.
